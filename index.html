How it works

Every 2026/27 result is compared with the same fixture from 2025/26: Chelsea at home to Arsenal against last season's Chelsea at home to Arsenal. A win is 3 points and a draw is 1, so if Chelsea drew that game last season and win it this season, Chelsea's swing is +2 and Arsenal's is -1.

The projection adds each club's swing to last season's points total, so it assumes the rest of the season goes exactly as last season did.

The promoted clubs weren't in the Premier League last season, so each takes on the results of a relegated club: the Championship winners take 18th place's results, the runners-up 19th, and the play-off winners 20th.
